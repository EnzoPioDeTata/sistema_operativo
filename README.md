# VirtualC OS — Sistema Operativo Simulato

VirtualC OS è un programma realizzato interamente in Linguaggio C, progettato per funzionare completamente da terminale.  
Non è un vero sistema operativo, ma **simula il comportamento di una shell** come Bash o PowerShell, offrendo un ambiente interattivo con comandi personalizzati e funzioni integrate.

## Funzionalità principali
VirtualC OS mette a disposizione un prompt interattivo che permette di eseguire diverse operazioni, tra cui:
- Creare file
- Visualizzare il contenuto dei file
- Eliminare file
- Mostrare data e ora correnti
- Aprire una semplice calcolatrice
- Avviare un mini‑gioco
- Pulire la finestra del terminale

## Stile e Aspetto Visivo
VirtualC OS adotta uno stile minimale e leggibile, ispirato ai terminali classici.  
L’interfaccia è composta da un **prompt colorato** che mostra esclusivamente il nome del sistema, mantenendo un aspetto semplice e minimale.

I colori sono scelti per rendere l’esperienza più chiara e piacevole:

- **Ciano** per il nome del sistema nel prompt  
- **Verde** per messaggi di successo (operazioni completate)  
- **Giallo** per informazioni o avvisi  
- **Rosso** per errori o input non valido  
- **Bianco** per il testo standard e l’output dei comandi

Questo schema cromatico permette di riconoscere rapidamente il tipo di messaggio senza confusione, pur mantenendo un design essenziale.  
L’obiettivo è offrire un ambiente semplice, pulito e minimalista, senza elementi grafici superflui.
